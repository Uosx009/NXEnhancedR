This repo is **fixes only**. No new features, ever.

✅ **Will be fixed:**
- Something that used to work is now broken (NextDNS site change, Chromium change, etc.)

❌ **Will be closed and deleted without response:**
- Feature requests
- "It would be nice if..."
- Questions about adding functionality

If something genuinely broke, please use the Bug report template and fill in every field — especially the console errors. Reports with no details can't be investigated.

I maintain this for my own daily use. If it breaks for me, it gets fixed. If it breaks only for you, I'll try to help but there are no guarantees or timelines.
